# 参考产品研究基线

## 1. 研究范围

研究日期：2026-10-15

研究内容：

- 公开 `sitemap.xml`
- React 路由配置
- 首页懒加载模块
- 登录后桌面端 72 个代表路由
- 移动端 6 个关键页面
- 页面控件、表单、弹层、图表、画布和 API 请求

规模：

- 公开 sitemap：232 个 URL
- 代码层路由模式：约 280 个
- 登录后巡检状态：78 个
- 独立 API：38 个

## 2. 页面壳层

### PlatformShell

适用范围：

- 首页
- 模型对话
- 超级 Agent
- 新绘画
- 图片处理
- 翻译
- 视频
- 音乐
- 股票
- 设计
- 图表
- 会员与积分

特征：

- 固定左侧产品导航
- 顶部全局搜索
- 积分、会员和头像
- 工具内部可能有二级侧栏

### WorkbenchShell

适用范围：

- 新版 PPT
- 法律文书
- AI 图表
- 图片工具集

特征：

- 左侧配置或分类
- 中央主要编辑区
- 右侧历史、导出或快捷操作

### DiscoveryShell

代表页面：

- `/map`

特征：

- 工具、模型、智能体和排行榜
- 统计数字
- 收藏
- 分类导航

### MediaStudioShell

代表页面：

- `/tts`
- `/AIMusic`
- 新版视频工作台

特征：

- 主导航弱化
- 工具自己的标题和侧栏
- 配置、生成、音频或视频结果占据主要区域

### LegacyShell

代表页面：

- 旧版 PPT
- 旧版视频
- PDF、白板、3D 建模等兼容页

- 全局积分显示

## 5. 全局接口

几乎所有页面都会请求：

- `api/v3/user/info`
- `api/v3/user/system/check_migration`
- `api/v2/config/init`
- `api/v2/config/controller`

功能接口按领域拆分：

- 模型和模型分组
- Agent
- 绘画历史和示例
- 视频任务和灵感
- PPT 和模板
- 音乐模型
- 语音和声音克隆
- 法律模板
- 积分和账单
- 商店
- 导航和收藏

## 6. 路由注意

- `/draw/text2image` 会跳转到 `/newchat`
- `/aiSearch/searchByhome` 会跳转到 `/newchat`
- `/newchat/agent` 当前为空
- `/aiDesign/aiResume` 当前只有壳层
- PDF、白板、3D 建模等页面成熟度较低

实现时应建立路由迁移表，区分成熟工作台、标准页面、旧版兼容页和占位页。

## 7. 移动端

- 首页使用顶部横向导航
- 聊天和绘画使用底部固定操作条
- PPT 使用配置欢迎弹层
- 工具地图移动端信息密度较高
- 不能只做桌面端等比缩放

## 8. 研究后的实施建议

优先顺序：

1. 全局壳层、账户、积分、会员
2. 模型对话和 Agent
3. 新绘画和图片处理
4. 新版 PPT、翻译、论文、思维导图
5. 视频、音频、音乐和声音克隆
6. 股票投研
7. 设计、法律和通用工具
8. 旧版和占位页

详情版研究结论曾保存在工作区 `参考产品-auth-research/RESEARCH-CONCLUSION.md`。正式开发时只迁移经过清洗的结论，不把登录会话或原始隐私数据放入仓库。
