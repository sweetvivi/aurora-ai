# 待确认问题

本文件用于记录需要用户后续回答的问题。用户回答后，应同步更新 `docs/DECISIONS.md`。

## 产品与范围

- 首发是演示版、内测版还是直接正式商用？
- 首发需要覆盖哪些产品线？
- 是否要求像素级接近参考产品，还是保持同类结构即可？
- 是否保留股票、彩票、命理等高风险或低优先级功能？
- 需要支持哪些语言和地区？

## 技术栈

- 前端使用 React，还是复用现有 Vue 项目经验？
- 后端从零开发，还是复用 `ai-workbench-api`？
- 是否沿用 PostgreSQL、Redis 和 Prisma？
- 是否需要管理后台和运营后台？

## 登录与账户

- 首发使用手机号、邮箱、微信，还是先使用开发登录？
- 是否必须绑定手机号？
- 是否需要多端同步会员和积分？

## 模型与 API Key

- 首批接入哪些模型供应商？
- 新 API Key 将替换哪些旧模型？
- 是否要求前后端统一模型别名，避免直接暴露供应商名称？
- 是否允许模型失败时自动回退？

## 文件与存储

- 文件保存在本机、MinIO、阿里云 OSS，还是其他 S3 服务？
- 用户文件和生成结果的保留周期是什么？
- 是否需要 CDN？

## 支付与商业化

- 是否真实接入微信或支付宝？
- 积分、会员和订单是否首发上线？
- 退款、发票和会员到期规则如何处理？

## 部署与运维

- 正式域名是什么？
- 部署到哪台服务器或云平台？
- 是否使用 Docker Compose、Kubernetes 或现有运维体系？
- 是否需要 HTTPS、反向代理、对象存储和 CDN 配置？

## 合规与安全

- 是否面向中国大陆公开运营？
- 使用哪个主体完成备案和协议？
- 是否需要内容审核、实名、未成年人保护和生成内容标识？
- 声音克隆、数字人和人脸视频如何取得用户授权？
- 股票和金融内容是否需要额外免责声明或资质？

## 仓库与协作

- 远端仓库使用哪个账号推送？
- 当前 HTTP 推送需要 Gitea 密码或访问 Token；采用 Git Credential Manager 登录，还是配置 SSH？
- 分支策略使用 `main` 直推，还是功能分支加合并请求？
- 是否需要提交钩子和 CI？
- 仓库采用什么许可证？

## 回答记录

用户回答后，将结果写入 `docs/DECISIONS.md`，并在本文件对应问题下标记：

```text
状态：已确认
决策编号：D-XXX
```
