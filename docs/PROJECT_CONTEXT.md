## 7. 工程原则

- 优先实现可验证的垂直切片，不做只有外观的空页面。
- 复杂能力走任务队列，提交和结果查询分离。
- 积分采用预扣、结算、失败退回。
- 所有第三方模型通过统一适配层接入。
- 页面通过工具注册表和工作台引擎复用。
- 公开页面需要 SEO 元数据，工具页需要独立路由。
- 移动端单独设计关键工作流，不能只依赖桌面端压缩。
- 密钥和用户隐私数据不得进入 Git。
- Mock provider 只用于自动化测试和受控兜底，不作为首批真实模型的唯一实现。
- 供应商密钥不得以明文写入数据库；数据库只保存供应商元数据、引用或加密后的密文。
- 支付订单必须从第一版就采用状态机和幂等设计，不能由前端直接标记已支付。
